# English as the official language

- **Date:** 2026-11-03
- **Status:** Accepted

## Context

PLUNZ spans multiple products and repositories. A common language keeps their documentation and collaboration consistent.

## Decision

English is the official language of the PLUNZ organization. Use it for repository documentation, code comments, issues, pull requests, commit messages, and product copy by default. Other languages may be added to products through an explicit localization plan.

## Consequences

New shared content is written in English. Existing content should be translated when touched or migrated. Product-specific localization remains possible when planned.

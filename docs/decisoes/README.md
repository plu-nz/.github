# Decisões compartilhadas

Registre aqui escolhas que afetem a marca ou mais de um produto. Use um arquivo por decisão, com data, contexto, decisão e consequências. Propostas ainda não aprovadas devem ser identificadas como propostas.

As preferências e fatos atuais estão em `docs/contexto.md`; não os transforme em decisões definitivas sem validação.
